# MiningShop — сайт v3: видеокарты, серверы и сборки для ИИ

Новый сайт miningshop.ru: магазин видеокарт для нейросетей, серверов и сборок, выкуп и трейд-ин видеокарт; асики и майнинг —
вторым планом. Структура — по Вордстату за 08.09–07.10.2026 (документ «MiningShop: SEO-структура под ИИ и видеокарты»).
Старые адреса с 2017 года сохранены там, где это возможно (`/catalog/videokarty/`, `/catalog/mayning_fermy/`,
`/catalog/komplektuyushchie/`, `/services/`, `/blog/`), остальные ведут 301-редиректом на ближайший раздел.

Черновик: https://jokerfrombali.github.io/miningshop-site-v3/ (закрыт от индексации).

## Сборка

```bash
python3 src/build.py                          # черновик для GitHub Pages: noindex, префикс /miningshop-site-v3
MS_BASE= MS_TEMP=0 python3 src/build.py       # боевая сборка для miningshop.ru: индексируется, с .htaccess
```

Всё в корне репозитория, кроме `src/` и этого файла, — результат сборки; руками не править.

## Где что

| Файл | Что внутри |
|---|---|
| `src/data/prices.csv` | Цены и наличие по моделям видеокарт. Заполненная цена появляется на сайте, в разметке и в `feed.yml` для Авито и Маркета |
| `src/pages_ai.py` | Видеокарты (≈ 22 модели), серверы для ИИ (по задаче, по числу карт, по модели), сборки и тушки |
| `src/pages_farms.py` | Фермы на видеокартах `/catalog/mayning_fermy/`: GPU-ферма для ИИ, фермы на NVIDIA, ферма на RTX 3090, ферма для биткоина; статьи «Ферма или сервер» и «Законен ли майнинг» |
| `src/pages_buyback.py` | Выкуп, трейд-ин, б/у с гарантией, карты из Китая, сборка серверов, аренда GPU, рендер |
| `src/pages_aiblog.py` | 19 справочных статей про железо для ИИ и калькулятор видеопамяти `/calc/vram/` |
| `src/pages_parts.py` | Комплектующие: NVLink, SXM2, охлаждение Tesla, райзеры, платы, корпуса, БП, асики |
| `src/pages_asic.py`, `pages_table.py` | Асики и калькулятор доходности |
| `src/redirects.py`, `src/data/legacy_urls.txt` | Редиректы с 1 639 адресов старого сайта; итог — `redirects.csv` и `.htaccess` (боевая сборка) |
| `src/pages_legacy.py`, `src/data/legacy_weight.tsv` | Страницы, возвращённые на старые адреса ради веса; таблица: старый адрес → входы из поиска 2021–22 и 2024–25 → что с ним сейчас (живая страница или 301 куда) |
| `llms.txt` | Карта сайта для нейросетей |
